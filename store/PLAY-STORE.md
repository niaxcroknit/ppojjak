# Google Play 등록 자료 — 뽀짝 우주 대탈출

자세한 순서는 `ANDROID-PLAY-GUIDE`(Claude 문서)를 보세요. 이 파일은 복사해 붙여 넣을 문구와 파일 목록입니다.

## 올릴 파일 (`store/` 폴더)

| Play Console 항목 | 파일 | 규격 |
| --- | --- | --- |
| 앱 아이콘 | `icon-512.png` | 512×512 PNG(32비트) |
| 그래픽 이미지 | `feature-graphic-1024x500.png` | 1024×500 PNG(알파 없음) |
| 휴대전화 스크린샷 | `screenshots/01.png` ~ `06.png` | 1080×1920 PNG(알파 없음), 6장 |
| 캡션 없는 스크린샷(필요하면) | `screenshots/raw/01~06.png` | 1080×1920 |
| 개인정보처리방침 | 노션 공개 페이지 https://app.notion.com/p/4024235ad3ee80668ecfcca2cbbf8526 | Play Console에 이 주소 입력 (`privacy-policy.html`은 같은 내용의 백업) |

이미지는 `python3 tools/make_store_assets.py`로 언제든 다시 만들 수 있어요(게임 그림 코드에서 직접 뽑음).

**자세한 설명**:
외계인은 귀여운 것부터 잡아간대요… 그런데 아이템을 먹을수록 내 우주선이 점점 귀여워진다면?

● 별탄이 LV3까지 업그레이드! 게이지가 차면 "귀여움 폭주"로 다 박살
● ★별조각을 모아 상점에서 기체 색 · 불꽃 색 · 업그레이드
● 오늘의 미션 · 오늘의 코스(모두 같은 길)로 친구와 겨루고, 결과는 카톡으로 바로 자랑

**카테고리**: 게임 › 아케이드 · **태그 예시**: 아케이드, 캐주얼, 픽셀, 한 손 플레이
