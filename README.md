# 뽀짝 우주 대탈출 · v0.16

> 개인정보처리방침: https://app.notion.com/p/4024235ad3ee80668ecfcca2cbbf8526
>
> 글꼴: 이 게임에는 ㈜원스토어가 제공한 원스토어 모바일 POP체(제목·알림)와 네이버 나눔스퀘어 네오(보조, OFL)가 적용되어 있습니다(`web/fonts/`의 라이선스 파일).
>
> 정식 이름(v0.16~): **뽀짝 우주 대탈출 - 귀여우면 잡혀가는 슈팅 게임**. 예전 이름 "네온 드리프트"는 같은 이름의 게임이 있어서 바꿨어요. 저장 키(`neon-drift-*`)·패키지명·파일명은 저장이 끊기지 않게 그대로 둡니다.

귀여운 우주선을 한 손으로 몰며 운석과 외계인을 피하는 세로형 레트로 미니게임입니다. 외계인은 귀여운 것부터 데려갑니다.

## 폴더 구조

```
web/                  ← 게임 원본은 여기 한 벌뿐입니다 (index.html, style.css, game.js)
android/              ← WebView 앱 (web/ 폴더를 그대로 assets로 사용)
tools/build_single.py ← web/ → index.html 단일 파일 생성 (GitHub Pages 첫 화면)
tests/run_tests.py    ← 자동 검사 (이동감 보존 포함) — 수정 후 꼭 실행
store/                ← Play 등록 자료 (아이콘, 피처 그래픽, 스크린샷, 개인정보처리방침, PLAY-STORE.md)
index.html ← 브라우저로 바로 여는 단일 파일 (빌드 결과물 = 웹에서 하는 게임)
```

`web/`만 고치면 됩니다. 수정 후에는 `python3 tests/run_tests.py`를 실행하세요. 단일 HTML도 자동으로 다시 만들고 78개 항목을 검사합니다. 처음 한 번은 `pip install playwright && python -m playwright install chromium`이 필요합니다.

## 바로 플레이

웹 주소 https://niaxcroknit.github.io/ppojjak/ 에서 바로 할 수 있어요. 로컬에서는 `index.html`(또는 `web/index.html`)을 브라우저로 엽니다. 주소 끝에 붙일 수 있는 옵션:

- `?app=1` — 앱과 같은 전체 화면 레이아웃
- `?debug=1` — 결과 화면에 최근 30판 기록(평균 생존 시간·점수·사망 원인)과 JSON 복사 버튼

조작

- 이동: 드래그 / 방향키 / WASD (한글 입력 상태에서도 동작)
- 위장: 화면 짧게 탭 / 위장 버튼 / Space / M
- 일시정지: Ⅱ / Esc / 다른 창으로 이동 시 자동. 재개할 때 3·2·1
- 도감·꾸미기 닫기: Esc / Android 뒤로가기
- 사운드(효과음 + 배경 음악), 진동(휴대폰·앱) — 설정은 저장됨

- 결과 화면: 버틴 시간·단계, 근접 회피 횟수와 최고 연속, 아이템·새 발견·장식 해금, 별탄 명중.
- **UFO 격퇴**: 별탄 1발 = 체력 1. 주 UFO 체력 10(격퇴할 때마다 다음 UFO +3, 8초 뒤 재등장), 추가 UFO 6, 하이퍼로 들이받으면 3. 맞을 때마다 체력 칸이 보이고, 격퇴하면 외계인이 탈출 캡슐을 타고 울면서 도망갑니다. **주 UFO를 격퇴하면 뺏긴 인형을 되찾습니다.** 주 UFO 200점, 추가 UFO 120점.
- **행성 여정과 모선(보스)**: 하단에 다음 행성까지 진행 막대. 네온 성운(45초) → 별사탕 행성(50초) → 얼음 행성(55초), 이후 회차가 올라가며 반복(보스 체력 +50%씩). 막대가 차면 모선이 등장하고, 창살 안에 갇힌 친구가 보입니다.
  - 몽몽(털뭉치 집착러): 점선 예고 뒤 집게팔 — 잡히면 포획(인형 규칙 동일)
  - 쭈쭈(반짝이 수집가): 기체를 향한 반짝이 탄 3~5발 — 맞으면 운석과 같음
  - 꾸꾸(이상한 거 좋아하는): 집게 + 탄 번갈아
  - 모선전에는 별탄 캡슐이 바로, 그리고 11초마다 보급되고 일반 UFO는 숨으며 운석 줄은 30% 줄어듭니다. 45초 안에 격퇴하면 +500점(회차마다 더), 현상수배 체포, **친구 구출** → 다음 행성. 못 잡으면 모선이 도망가고 구출 없이 다음 행성.
- **구한 친구**: 토끼 토토 · 병아리 삐약이 · 고양이 냥냥. 다음 판부터 기체를 졸졸 따라다닙니다(외형만, 능력 없음). 대신 **귀여울수록 위험** — 친구 1명당 UFO 조준 간격이 0.15초 짧아집니다.
- **여정 화면**(시작 화면의 "여정 · 지도"): 행성 지도, 구한 친구, 현상수배 포스터(체포 도장).
- **오늘의 코스**: 시작 화면의 "오늘의 코스" 버튼. 날짜마다 운석 줄·아이템 순서가 모두에게 똑같아 친구와 같은 판으로 겨룰 수 있습니다. 오늘의 코스 최고 기록 표시.
- **결과 공유**: 결과 화면의 "결과 공유하기" — 점수·도착 행성·격퇴·하이퍼·구출과 게임 링크가 담긴 문구를 복사(앱에서는 공유 시트). 링크는 `game.js`의 `SHARE_URL`(출시 후 Play 주소로 교체).
- **하이퍼 드리프트**: 화면 아래 ⚡ 게이지(근접 회피 +3, 아이템 +1, UFO 격퇴 +2, 모선 격퇴 +4, 12칸, 끊겨도 줄지 않음)가 차면 충전되고 ⚡ 하이퍼 버튼(PC: H)이 빛납니다. 누르면 4초 동안 무적 질주 — 세상이 2.4배 빨라지고, 부딪힌 운석은 부서지고(+15점), UFO는 튕겨 나가며, 생존 점수 2배. **대가**로 가면·목숨·켜진 효과(왕관·자석·감속·혼란·별탄·착용 장식 효과)를 모두 떨어뜨립니다. 인형과 꾸미기 장식은 그대로. 끝날 때 0.5초 감속 + 1.2초 무적, 떨어뜨린 것 중 최대 2개가 다시 떨어집니다(조각·도감 집계 제외). 하이퍼 중 먹은 아이템은 황금 조각이 되지 않습니다. 충전을 아껴 둘지 위기 탈출에 쓸지는 플레이어의 선택. 기체 이동 속도는 그대로입니다.
- **오늘의 미션**: 날짜마다 하나(11종 중). 한 판 안에 달성하면 완료, 보상으로 장식 조각 +1. 연속 달성 일수 표시.
- **첫 판 힌트**: 연습 비행에서 다룬 것 외(근접 회피·추격 게이지·취향·모선 등)는 상황이 처음 생길 때 한 번씩 알려줍니다.

## Android 앱 빌드

요구사항: Android Studio(최신), JDK 17+, Android SDK 36. Gradle wrapper(8.14.3) 포함.

1. Android Studio에서 `android` 폴더를 열고 Run. 터미널: `cd android && ./gradlew assembleDebug`
2. `applicationId`는 `com.ppojjak.spaceescape`(이미 Play Console에 등록됨 — 변경 금지)
3. Build → Generate Signed App Bundle로 AAB 생성
4. 등록 문구·설문 답변·체크리스트는 `store/PLAY-STORE.md`

앱 설정: targetSdk/compileSdk 36, minSdk 26, 세로 고정, edge-to-edge, 뒤로가기 처리, WebView 렌더러 종료 시 자동 복구(크래시 방지), 자동 백업(게임 진행만), 진동(VIBRATE), 오래된 WebView 안내 화면, 외부 네트워크 차단.
